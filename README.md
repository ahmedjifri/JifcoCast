# Jifco Cast

عكس الشاشة (Screen Mirroring) عبر الشبكة المحلية — من أندرويد أو ويندوز إلى أي جهاز أندرويد / أندرويد تي في (كروم كاست مع جوجل تي في، شاومي تي في…).

## المكوّنات
- `app/` — تطبيق أندرويد (كوتلن + كومبوز): مرسل ومستقبل في تطبيق واحد، يسأل عن الدور عند كل تشغيل.
- `shared/` — البروتوكول المشترك وأدوات مساعدة.
- `pc/` — «Jifco Cast للحاسب»: مرسل ويندوز ببايثون يكلّم المستقبل بنفس البروتوكول.

## البناء
افتح المجلد في أندرويد ستوديو (AGP 9.4، Gradle 9.6) وشغّل `app`.

للحاسب:
```
cd pc
install.bat
run.bat
```

## الاستخدام
1. على الشاشة (كروم كاست): افتح Jifco Cast → **Receiver**.
2. على الجوال/اللوحي أو الحاسب: Jifco Cast → **Sender** → «ابحث عن المستقبلات» → «عكس الشاشة».
